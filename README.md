# musica-prep

Preparation work for **Musica**, a hosted web-based BluOS player controller —
see [`musica/README.md`](musica/README.md) for what that project is and why,
and [`musica/MOTIVATION.md`](musica/MOTIVATION.md) for the problems it's meant
to solve.

No code has been written yet. This repository exists to get the planning
material under version control before the number of files and drafts on disk
becomes unmanageable — not because the plan is finished.

## Layout

- **`musica/`** — the project itself: motivation, design principles, plan,
  and protocol notes for the app to be built.
- **`bluos-api/`** — research into the BluOS HTTP API that `musica` will
  depend on: probes, captures, and a specification built from testing and
  from surveying third-party BluOS projects.
- **`todo-bluos-stuff`** — loose scratch notes, unsorted.

## Status

Early and unsettled. Content in here will be reorganized, rewritten, and
possibly split up as the plan solidifies. Treat everything as a draft.

## Public scope

This repo started private while it's worked out how much of this material
can reasonably be shared publicly. Nothing here should be assumed public
until that's been decided.
